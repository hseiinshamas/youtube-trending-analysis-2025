# Trending YouTube Videos Analysis (2025-26 Project)

## Overview
This project analyzes the **Trending YouTube dataset** across multiple countries.  
It performs **data cleaning, exploration, and aggregation**, extracting insights such as top channels, popular tags, trending videos, and patterns over time.  

Implemented in **Python** with **Jupyter Notebook** for reproducible workflows.

## Tools & Libraries
- Python 3.x  
- Jupyter Notebook  
- `pandas`, `numpy`, `glob`, `os`, `json`
